# Blogville 요구사항 명세서

> 블로그들이 모여 사는 마을. 글을 쓰고 꾸미면서 내 캐릭터와 블로그를 키워 가는 게임형 블로그 서비스.

- 작성자: 이진행
- 작성일: 2026-10-02
- 버전: 0.2 (사이트 자체 회원가입·관리자 추가)

## 1. 개요

### 1.1 배경

Tistory 같은 블로그는 글쓰기 도구로는 훌륭하지만, 꾸준히 쓰게 만드는 동기가 약하다.
Blogville은 **블로그 활동을 게임 보상과 연결**해서, 글을 쓸수록 캐릭터와 블로그 공간이 성장하는 경험을 준다.

### 1.2 목표

1. **글쓰기와 꾸미기가 우선**인 블로그를 만든다. 게임 요소는 글쓰기를 돕는 역할에 머문다.
2. 소셜 로그인으로 가입 장벽을 낮춘다.
3. 중앙 광장에서 다른 사람의 블로그를 자연스럽게 발견하게 한다.
4. 2D로 완성한 뒤 2.5D(아이소메트릭)로 확장한다.

### 1.3 범위 밖 (이번 프로젝트에서 하지 않는 것)

- 실시간 멀티플레이 (광장에서 다른 사람이 움직이는 모습을 실시간으로 보기)
- 유료 결제 (코인은 활동으로만 얻는다)
- 모바일 앱 (반응형 웹으로 대응)

## 2. 사용자

| 사용자 | 설명 |
|---|---|
| 방문자 | 로그인하지 않은 사람. 공개 글과 블로그, 광장을 구경할 수 있다 |
| 회원 | 소셜 로그인으로 가입한 사람. 자기 블로그를 운영하고 다른 블로그와 교류한다 |
| 관리자 | 아이템과 기본 데이터를 관리한다 (초기에는 시드 데이터로 대체) |

## 3. 핵심 사용자 흐름

```text
[처음 방문] → 소셜 로그인 (네이버 / 카카오 / 구글)
     │
     ▼ 최초 가입이면
[온보딩] 닉네임 → 블로그 이름·주소 → 기본 캐릭터 고르기 (3종 중 1)
     │
     ▼
[중앙 광장] 내 캐릭터로 돌아다님
     ├─ 🏠 내 집  → 내 블로그
     ├─ 🏘 이웃집들 → 다른 사람 블로그 (최근 글 쓴 블로그, 내 이웃)
     ├─ 📮 우체통 → 일일 보상(출석)
     ├─ 🏪 상점   → 캐릭터·배경 구매
     └─ 📋 게시판 → 마을 최신 글
     
[내 블로그] 상단: 미니룸(배경 + 캐릭터) / 하단: 글 목록
     ├─ ✏️ 글쓰기 → 저장 → 경험치·코인 획득
     └─ 🎨 꾸미기 → 보유한 캐릭터·배경 장착
```

## 4. 기능 요구사항

우선순위는 **MoSCoW**로 표시한다.
- **M**ust: 없으면 서비스가 성립하지 않음
- **S**hould: 있어야 기획 의도가 살아남
- **C**ould: 여유가 있으면 추가
- **W**on't: 이번에는 하지 않음

### 4.1 회원 / 인증 (AUTH)

| ID | 요구사항 | 우선 |
|---|---|---|
| AUTH-01 | 네이버, 카카오, 구글 계정으로 로그인할 수 있다 | M |
| AUTH-07 | 사이트 자체 아이디(영문 소문자·숫자·_ 4~20자)와 비밀번호(8자 이상)로 회원가입·로그인할 수 있다 | M |
| AUTH-08 | 관리자 계정은 관리자 페이지에서 통계와 회원 목록을 보고, 어떤 글이든 삭제할 수 있다. 일반 회원에게는 관리자 페이지가 보이지 않는다 | S |
| AUTH-02 | 처음 로그인하면 온보딩(닉네임, 블로그 이름·주소, 기본 캐릭터 선택)을 거친다. 온보딩을 마치기 전에는 다른 기능을 쓸 수 없다 | M |
| AUTH-03 | 닉네임과 블로그 주소는 서비스 전체에서 중복될 수 없다 | M |
| AUTH-04 | 로그아웃할 수 있다 | M |
| AUTH-05 | 같은 사람이 여러 소셜 계정을 하나의 회원에 연결할 수 있다 | C |
| AUTH-06 | 회원 탈퇴 시 개인정보와 글을 삭제한다 | S |

### 4.2 블로그 (BLOG)

| ID | 요구사항 | 우선 |
|---|---|---|
| BLOG-01 | 회원 한 명은 블로그 하나를 가진다 | M |
| BLOG-02 | 블로그 주소는 `/@블로그주소` 형식이다 | M |
| BLOG-03 | 블로그 이름과 소개를 수정할 수 있다 | M |
| BLOG-04 | 블로그 상단에 **미니룸**(장착한 배경과 캐릭터)이 보인다 | M |
| BLOG-05 | 블로그마다 카테고리를 만들고 순서를 바꿀 수 있다 | S |
| BLOG-06 | 블로그 방문자 수(전체, 오늘)를 보여준다 | C |

### 4.3 글 (POST)

| ID | 요구사항 | 우선 |
|---|---|---|
| POST-01 | 에디터(제목, 굵게, 목록, 인용, 코드 블록, 링크)로 글을 작성·수정·삭제할 수 있다 | M |
| POST-02 | 글은 공개 / 비공개를 정할 수 있다. 비공개 글은 작성자만 본다 | M |
| POST-03 | 글에 카테고리를 지정할 수 있다 | S |
| POST-04 | 글에 태그를 여러 개 달 수 있고, 태그별로 모아볼 수 있다 | S |
| POST-05 | 글 목록은 최신순, 페이지 단위로 보여준다 | M |
| POST-06 | 글 조회수를 센다 | S |
| POST-07 | 글에 이미지를 첨부할 수 있다 | C |
| POST-08 | 작성 중인 글을 임시 저장할 수 있다 | C |

### 4.4 교류 (SOCIAL)

| ID | 요구사항 | 우선 |
|---|---|---|
| SOC-01 | 회원은 글에 댓글을 쓰고, 자기 댓글을 삭제할 수 있다 | M |
| SOC-02 | 댓글에 답글(1단계)을 달 수 있다 | C |
| SOC-03 | 회원은 글에 공감(♥)할 수 있다. 한 글에 한 번만 가능하고 취소할 수 있다 | M |
| SOC-04 | 다른 블로그를 이웃으로 추가하고, 이웃의 새 글을 모아볼 수 있다 | S |
| SOC-05 | 마을 전체의 최신 공개 글을 볼 수 있다 | M |

### 4.5 캐릭터 / 성장 (GAME)

| ID | 요구사항 | 우선 |
|---|---|---|
| GAME-01 | 가입 시 기본 캐릭터 3종(사람 / 동물) 중 하나를 받는다 | M |
| GAME-02 | 활동으로 **경험치**를 얻고, 경험치에 따라 **레벨**이 오른다 | S |
| GAME-03 | 활동으로 **코인**을 얻는다 | S |
| GAME-04 | 하루 한 번 **출석 보상**을 받는다. 연속 출석 7일째에는 추가 보상을 준다 | S |
| GAME-05 | 보상 규칙 (아래 표). 같은 활동의 보상은 **하루 상한**이 있다 | S |
| GAME-06 | 레벨이 오르면 알림을 보여준다 | C |

**보상 규칙 (초안)**

| 활동 | 경험치 | 코인 | 하루 상한 |
|---|---|---|---|
| 출석 | 10 | 20 (7일 연속 시 +50) | 1회 |
| 글 작성 (공개, 본문 100자 이상) | 30 | 30 | 3회 |
| 댓글 작성 | 5 | 5 | 10회 |
| 내 글이 공감 받음 | 2 | 2 | 20회 |

- 글을 지웠다 다시 쓰는 식의 반복으로 보상을 늘릴 수 없도록 하루 상한을 둔다.
- 남의 글에 댓글을 달 때만 보상한다 (내 글에 단 댓글은 제외).

### 4.6 상점 / 꾸미기 (SHOP)

| ID | 요구사항 | 우선 |
|---|---|---|
| SHOP-01 | 상점에서 캐릭터와 배경 아이템을 코인으로 살 수 있다 | S |
| SHOP-02 | 일부 아이템은 일정 레벨 이상이어야 살 수 있다 | S |
| SHOP-03 | 코인이 부족하면 살 수 없다. 코인은 음수가 될 수 없다 | S |
| SHOP-04 | 내 인벤토리에서 보유한 캐릭터와 배경을 **장착**할 수 있다. 보유하지 않은 아이템은 장착할 수 없다 | M |
| SHOP-05 | 미니룸에 가구를 배치할 수 있다 | C |

### 4.7 광장 (TOWN)

| ID | 요구사항 | 우선 |
|---|---|---|
| TOWN-01 | 로그인하면 중앙 광장에서 시작한다 | M |
| TOWN-02 | 내 캐릭터를 키보드(방향키, WASD)와 클릭/터치로 움직일 수 있다 | M |
| TOWN-03 | 광장의 건물·오브젝트에 다가가 상호작용하면 해당 화면(내 블로그, 상점, 출석, 게시판)으로 이동한다 | M |
| TOWN-04 | 광장에 최근 글을 쓴 블로그들의 집이 나타나고, 들어가면 그 블로그로 이동한다 | S |
| TOWN-05 | 광장을 2.5D(아이소메트릭)로 업그레이드한다 | S |
| TOWN-06 | 다른 사람이 광장에서 움직이는 모습을 실시간으로 본다 | W |

## 5. 비기능 요구사항

| ID | 분류 | 요구사항 |
|---|---|---|
| NF-01 | 보안 | 소셜 로그인 Client Secret, DB 접속 정보는 서버 환경 변수에만 둔다 |
| NF-02 | 보안 | 글 수정·삭제, 아이템 장착 등 모든 권한 검사는 **서버**에서 한다 |
| NF-03 | 보안 | 에디터로 작성한 HTML은 저장·출력 시 정화(sanitize)해서 XSS를 막는다 |
| NF-04 | 무결성 | 코인 지급·차감, 아이템 구매는 **트랜잭션**으로 처리한다. 중간에 실패하면 전부 취소된다 |
| NF-05 | 무결성 | 출석은 DB 제약조건으로 하루 한 번만 가능하게 한다 (동시에 두 번 눌러도 한 번) |
| NF-06 | 사용성 | PC와 모바일 화면 모두에서 쓸 수 있다 (반응형) |
| NF-07 | 성능 | 글 목록 첫 화면은 1초 안에 보여준다 |
| NF-08 | 운영 | `main`에 push하면 자동으로 배포된다 |

## 7. 용어

| 용어 | 뜻 |
|---|---|
| 미니룸 | 블로그 상단에 보이는 작은 방. 장착한 배경과 캐릭터로 꾸민다 |
| 광장 | 로그인 후 시작하는 마을 중앙. 다른 블로그와 기능으로 이어지는 허브 |
| 아이템 | 캐릭터, 배경, 가구 등 꾸미기 요소. 상점에서 사거나 기본으로 받는다 |
| 장착 | 보유한 아이템 중 미니룸과 광장에 보일 것을 고르는 것 |
| 원장(ledger) | 코인·경험치가 오간 기록. 잔액은 기록의 합계로 계산한다 |
